Project Overview & Tech Stack
Framework: Building a sub-feature for an EasyCard wallet application using the Flutter framework.

Core Functionalities: The base features require integrating a QR code scanner and an NFC scanner.

UI Design: Prioritizing clean aesthetics inspired by Shadcn and HeroUI.

Data Management: Currently utilizing mock data, with plans to refactor and migrate to a MySQL database in the future.

Coding Patterns & Guardrails
Paradigm: Prioritizing functional programming and writing code according to industry best practices.

No Hardcoding: Keeping the codebase clean and maintainable by strictly using variables instead of hardcoded values.

Quality Control: Running linting (flutter analyze) and automated testing (flutter test) every single time a task is completed.

AI Workflow & Git Conventions
Code & Git Preference: Focused on generating clean code and maintaining a streamlined Git workflow.

Automation: Once code passes both linting and testing successfully, it should automatically be committed and pushed to GitHub.

Commit Message Format: Adhering to a standardized <type>:<Message> format (e.g., feat:AddingNavigationBar).
